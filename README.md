# rex_chat_bot 

rex Bot is an AI-powered chatbot that enables users to send messages through a web interface and receive intelligent responses generated by a large language model. 

---

## Features

* Real-time chat interface
* AI-generated responses using Groq (LLaMA 3 model)
* FastAPI backend
* Simple frontend built with HTML, CSS, and JavaScript
* Asynchronous communication using Fetch API

## How It Works

1. User enters a message in the frontend
2. The message is sent to the FastAPI backend
3. The backend forwards the request to the Groq API
4. The AI model generates a response
5. The response is returned and displayed in the chat interface

---

## AI Model

* Model: `llama-3.3-70b-versatile`
* Provider: Groq

## Installation

### Clone the repository

```
git clone https://github.com/rexyy18/rex_chat_bot.git
cd rex_chat_boot
```

### Setup backend

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install fastapi uvicorn groq python-dotenv
```

### Configure environment variables

Create a `.env` file in the backend directory:

```
GROQ_API_KEY=your_api_key_here
```

### Run the server

```
uvicorn main:app --reload
```

The server will run at:

```
http://127.0.0.1:8000
```

### Run the frontend

Open:

```
frontend/index.html
```

## API

### POST /chat

Request:

```json
{
  "message": "Hello"
}
```

Response:

```json
{
  "reply": "Hi there! How can I help you?"
}
```
